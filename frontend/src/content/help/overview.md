# ImpactPilot help

ImpactPilot helps you document initiatives, estimate impact dimensions, attach evidence, and build scorecards for portfolio review.

## Workflow

1. **New initiative** — Use the intake wizard or create a blank initiative from the list.
2. **Maturity** — Exploratory initiatives hide euro monetization until maturity increases.
3. **Evidence** — Link PubMed or internal proof points to support estimates.
4. **Statement & scorecard** — Generate on the review step or from the initiative detail tabs.
5. **Portfolio** — See counts by tier, focus area, and impact score.

## Settings

LLM provider credentials are stored only in your browser (`impactpilot_llm_settings`). Keys are sent to the backend only when you test the connection or run inference.

## Export

From initiative detail or the intake review step, download JSON or Markdown exports when the record is ready.
